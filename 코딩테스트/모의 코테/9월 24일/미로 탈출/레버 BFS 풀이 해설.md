# 미로 탈출 레버 BFS 풀이 해설

- 문제: [미로 탈출](https://school.programmers.co.kr/learn/courses/30/lessons/159993) (Lv2)
- 코드: `solve_04_lever_bfs.py`
- 복잡도: 시간 O(R×C), 공간 O(R×C)
- 비교: 두 번 BFS 풀이(`solve_03_reconstruct.py`)도 O(R×C). 미로 전체를 한 번은 봐야 하므로 O(R×C)가 하한이다. 이 풀이는 BFS 횟수를 2번에서 1번으로 줄이고 코드를 짧게 만든 것이다.

## 1. 핵심 논리

레버에서 BFS를 한 번 돌려 방문하는 칸마다 이동 거리를 `dist`에 기록하면, `dist[S]`와 `dist[E]`가 바로 필요한 두 최단 거리다.

1. **처음 기록한 값이 최단 거리다.** BFS는 거리 0 → 1 → 2 순서로 퍼지므로 어떤 칸에 처음 도착했을 때의 거리가 최단이다. 이미 기록된 칸(-1이 아닌 칸)은 다시 기록하지 않는다.
2. **`dist[S]`(레버→S)를 S→레버 거리로 써도 된다.** 이동이 양방향이고 한 칸 비용이 모두 1이라, S→L 최단 경로를 거꾸로 걸으면 같은 길이의 L→S 경로가 된다.

답 = `dist[S] + dist[E]`. 둘 중 하나라도 -1이면 레버에서 그 칸으로 갈 길이 없으므로 -1.

## 2. 왜 레버에서 시작하나

필요한 두 거리 모두 레버가 한쪽 끝이다.

```text
S ─── L ─── E
  ①      ②
① 시작점 ↔ 레버
② 레버 ↔ 출구
```

| BFS 출발점 | 얻는 거리 | 결과 |
|---|---|---|
| 레버 | `dist[S]` = ①, `dist[E]` = ② | 한 번에 둘 다 |
| 시작점 | `dist[L]` = ①, `dist[E]`는 시작점↔출구라 ②가 아님 | 레버에서 한 번 더 필요 |
| 출구 | `dist[L]` = ②만 | 시작점에서 한 번 더 필요 |

## 3. 코드 줄별 의미

```python
pos = {maps[r][c]: (r, c) for r in range(R) for c in range(C) if maps[r][c] in "SLE"}
```

- 격자를 한 번 훑어 S, L, E 좌표를 딕셔너리에 모은다. `xyFinder`를 여러 번 호출하는 대신 한 줄로 끝난다.

```python
dist = [[-1] * C for _ in range(R)]
```

- `-1` = 아직 못 간 칸. 이 배열 하나가 **방문 여부**와 **거리**를 함께 담는다. `visited` 집합이나 큐에 거리를 같이 넣을 필요가 없다.

```python
lr, lc = pos["L"]
dist[lr][lc] = 0
```

- 첫 줄: `(행, 열)` 튜플을 두 변수로 나눠 받는다.
- 둘째 줄이 두 가지를 한다.
  - **거리 기준점**: 이웃 거리는 `dist[r][c] + 1`이므로 출발점이 0이어야 1, 2, 3으로 이어진다.
  - **방문 표시**: -1이 아니게 만들어 출발점이 다시 큐에 들어가지 않게 한다.
- 두 줄 풀이의 `queue = deque([(r,c,0)])`, `visited = set([(r,c)])`와 같은 역할이다.

이 줄이 없을 때 `maps = ["SLE"]` (정답 2):

| 단계 | 일어나는 일 |
|---|---|
| L을 꺼냄 | `dist[L]`이 -1이라 이웃 S, E 거리가 `-1 + 1 = 0` (실제는 1) |
| S를 꺼냄 | 이웃 L이 -1이라 미방문으로 보고 `dist[L] = 0 + 1 = 1`로 다시 넣음 |
| 결과 | `toS = 0`, `toE = 0` → 답 0 (정답 2) |

```python
if 0 <= nr < R and 0 <= nc < C and maps[nr][nc] != "X" and dist[nr][nc] == -1:
    dist[nr][nc] = dist[r][c] + 1
    q.append((nr, nc))
```

- 범위 안, 벽 아님, 미방문인 이웃만 넣는다.
- 거리는 넣을 때마다 올리는 게 아니라 **꺼낸 칸 거리 + 1**이다. 같은 칸에서 나온 4방향 이웃은 모두 같은 거리를 받는다.
- 넣는 순간 거리를 기록하므로 같은 칸이 큐에 두 번 들어가지 않는다.

## 4. 예시

`maps = ["SLE"]`

| 칸 | S | L | E |
|---|---|---|---|
| dist | 1 | 0 | 1 |

- `dist[S] = 1` → 시작점↔레버 1칸
- `dist[E] = 1` → 레버↔출구 1칸
- 답 = 2

## 5. 두 풀이 비교

| | 두 번 BFS | 레버 BFS 한 번 |
|---|---|---|
| BFS 횟수 | 2번 | 1번 |
| 좌표 찾기 | `xyFinder` 두 번 전체 탐색 | 딕셔너리 한 줄 |
| 방문 기록 | `visited` 집합 + 큐에 거리 저장 | `dist` 2차원 배열 하나 |
| 조기 종료 | 목표를 만나면 바로 반환 | 끝까지 퍼짐 (모든 칸 거리가 필요) |
| 시간 / 공간 | O(R×C) / O(R×C) | O(R×C) / O(R×C) |

## 6. 이 방법을 쓸 수 없는 경우

- 일방통행 칸이 있거나 방향마다 이동 비용이 다르면 S→L과 L→S 거리가 달라진다. 그때는 두 번 BFS로 푼다.
- 경유지가 여러 개이거나 순서가 정해져 있지 않으면 `(위치, 지금까지 거친 것)`을 상태로 두는 BFS를 쓴다.
