# 주차 요금 계산 복기

- 문제: [주차 요금 계산](https://school.programmers.co.kr/learn/courses/30/lessons/92341) (Lv2)
- 시도 이력: 첫 풀이 `solve.py`(2026-10-26) → D1 `solve_d1.py` → D7 `solve_d7.py`(2026-11-17)

## 2026-11-17 D7 복습

- 결과: 통과, 55분, 힌트 없음(H0)
- 풀이: `solve_d7.py`

### 핵심 풀이

- 유형: 구현(시뮬레이션) + 해시 집계
- `parking = {차번호: 입차시각(분)}`: 지금 주차 중인 차
- `parkTime = defaultdict(int)`: 차번호별 누적 주차 시간
- OUT이면 `parkTime[차] += 출차 - parking[차]` 후 `parking`에서 삭제
- 끝까지 남은 차는 23:59(1439분) 출차로 정산
- 요금은 누적 시간으로 차량당 한 번만 계산: 기본 시간 초과분은 `math.ceil(초과 / 단위시간) * 단위요금`

### 이번에 틀리거나 막힌 것

1. 시간복잡도를 O(n)으로 적었지만 차량 번호 정렬(`sorted`)이 O(k log k)라 전체는 O(n log n)이다.
2. `math.ceil`, `defaultdict` 문법이 정확히 기억나지 않아 찾아봤다.
3. 사전에 `.sort`를 쓰려 했다. `.sort()`는 리스트 메서드라 사전에는 없다. `sorted`로 수정했다.
4. `sorted(parkTime.items(), ...)` 결과가 `[(키, 값), ...]` 리스트인 걸 몰라서 처음엔 `.items()`로 다시 돌리려 했다. print로 확인하고 `for _, t in parkTime:`으로 고쳤다. 10/26 첫 풀이에서 `sorted` 결과에 `.values()`를 부른 것과 같은 실수다.
5. `if len(parking) >= 1:`은 필요 없다. 빈 사전을 for로 돌면 아무 일도 일어나지 않는다.

### 정리한 개념

```python
d.items()            # dict_items 객체. 리스트가 아니다
for k, v in d.items():   # 돌리면 (키, 값) 튜플이 하나씩 나온다

sorted(무엇이든)      # 원소를 꺼내 정렬한 새 "리스트"를 돌려준다. 원본은 그대로
sorted(d.items())    # [(키, 값), ...]  튜플 리스트
sorted(d)            # 키만 정렬한 리스트
sorted("cab")        # ['a', 'b', 'c']
```

- 튜플 리스트는 첫 번째 원소부터 비교하므로 `sorted(parkTime.items())`만으로 차량 번호순이 된다.
- 차량 번호는 4자리 고정(`"0000"`~`"9999"`)이라 문자열 순서와 숫자 순서가 같다. 이 문제에서는 `key=lambda x: int(x[0])`가 없어도 된다.
- 자릿수가 다른 숫자 문자열이면 `key=int`가 필요하다.

```python
sorted(["9", "10", "100"])           # ['10', '100', '9']
sorted(["9", "10", "100"], key=int)  # ['9', '10', '100']
```
